# Security

Use this project only on equipment you own or are authorised to service.

Do not post private raw dumps, RT reply hex, reconstructed maps, generated
reports or PIN screenshots in public issues. They can contain PINs, counters
and configuration data even when `--show-pins` was not used. For a sensitive
report, open an issue containing only
the affected model/version and ask the maintainer for a private contact route.

The current firmware sends only identity and memory-read commands. It does not
write memory or operate pumps, heaters, grinders or valves.
